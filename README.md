# AI-tools-and-practice-series
Educational materials for AI tools and practice series for Stanford faculty. Hosted by Lane Medical Library at Stanford Medicine.

## Session 1: Stanford AI Policies

- **Presentation:** https://vpatel43.github.io/AI-tools-and-practice-series/Stanford-AI-Policies.html
- **Follow along on your phone:** https://vpatel43.github.io/AI-tools-and-practice-series/Stanford-AI-Policies.html?follow

The follow-along link opens the Tally with every card listed. Tap **+** next to any tool, policy, guidance or case to add it to **My list**, add notes, then choose **Download PDF** for a takehome copy. Your list is saved only in your own browser; the page doesn't send it anywhere.
